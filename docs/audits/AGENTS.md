# Audit Documentation Instructions

- State scope, evidence, date, and limitations. Report only checks and reviews that actually ran.
- Cite exact canonical sections or stable IDs; avoid reproducing large source passages.
- Separate observed findings from recommendations and follow-up actions.
- Do not silently resolve open questions. Record the owner, decision, or future trigger required.
- Keep exploration bounded to the audit scope and distinguish “not inspected” from “no finding.”
