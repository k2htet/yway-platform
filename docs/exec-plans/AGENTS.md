# Execution Plan Instructions

- Apply the Stage and owner-authority rules in root `AGENTS.md`.
- Use these instructions only when a matching plan is already identified or the task requires one.
  For a required plan, inspect filenames first and read only the matching plan. Do not search plan
  contents for trivial work.
- Keep plans self-contained, scoped, and current. Record actual progress, discoveries, decisions,
  validation, and unresolved blockers.
- Route durable product or architecture outcomes to the referenced canonical document instead of
  storing them only in the plan.
- Close a plan only after its completion criteria and required checks are actually satisfied.
