# Architecture Documentation Instructions

- Apply the decision-authority rules in root `AGENTS.md`.
- Start from the changed architecture files and sections. Follow referenced decision IDs or
  filenames, check status headers, and read only directly applicable `ACCEPTED` decisions; do not
  enumerate or preload the decision directory.
- Read only the exact Product Contract sections implicated by the boundary.
- Preserve the distinction between logical responsibility and physical packages, services,
  applications, schemas, databases, providers, and deployment units.
- Record candidates and open questions without converting them into adopted choices.
- Keep privacy, consent, employer isolation, provenance, authorization, and offline outcomes
  explicit without choosing an unapproved mechanism.
