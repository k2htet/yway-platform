# Architecture Decision Instructions

- Apply the decision and owner-authority rules in root `AGENTS.md`.
- Use `000-TEMPLATE.md` and keep the status header explicit.
- Start from changed files and referenced decision IDs or filenames. Check status headers before
  reading only directly applicable `ACCEPTED` decisions; do not enumerate or preload all decisions.
- Check only the Product Contract and Architecture sections directly implicated by the decision.
- Record alternatives and consequences without presenting candidate technology as accepted.
- Keep unrelated product and roadmap changes outside an ADR task.
